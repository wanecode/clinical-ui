# Support

Use [GitHub Discussions](https://github.com/wanecode/clinical-ui/discussions) for
implementation questions and design-system conversation. Use
[GitHub Issues](https://github.com/wanecode/clinical-ui/issues) for reproducible
defects and scoped proposals.

Never attach protected health information, production screenshots, credentials
or private FHIR payloads. Replace them with the deterministic synthetic fixtures
provided by this repository.

Security and privacy reports belong in
[private vulnerability reporting](https://github.com/wanecode/clinical-ui/security/advisories/new).
