# Prototypes ENT / ORL

Ces trois directions ont été générées avec le mode intégré du skill `imagegen`. Elles servent de
références de composition ; elles ne sont pas embarquées dans le package distribué. Toutes les
données et tous les médias montrés sont synthétiques.

## 01 — Signal Desk

Fichier : `01-signal-desk.png`

```text
Use case: ui-mockup
Asset type: high-fidelity desktop web application design prototype, UI only
Primary request: Create “Signal Desk”, an original French audiology workstation screen. The
dominant panel is a pure-tone audiogram chart using red circle symbols and blue X symbols, with
dashed masked curves and one no-response arrow. Beside it, show the same values in a textual
table. Below, use narrow technical strips for speech audiometry, tympanometry, acoustic reflexes,
OAE and ABR. Include device quality, preliminary status, and governed PTA explicitly labeled as
derived reading support.
Scene/backdrop: flat full-screen web interface with abstract charts and tables only
Style/medium: polished product UI mockup, Swiss editorial precision mixed with analog signal
instrumentation
Composition/framing: 16:10 desktop, asymmetric 7/5 grid, compact section rail, generous margins
Color palette: warm ivory, graphite plotting field, ink, restrained signal red and cobalt blue,
tiny amber accent
Text (verbatim): “Audiométrie tonale”, “PTA dérivée — aide à la lecture”, “Données synthétiques”
Constraints: interface graphics only; accessible non-color encoding through O/X symbols, line
styles, labels, and table; synthetic values; no diagnostic claim
Avoid: humans, bodies, anatomy, medical photos, purple gradients, generic SaaS layout, logos,
watermark
```

Direction retenue : densité instrumentale, graphe sombre, table équivalente et repères droite /
gauche redondants.

## 02 — Sterile Lightbox

Fichier : `02-sterile-lightbox.png`

```text
Use case: ui-mockup
Asset type: high-fidelity desktop web application design prototype, UI only
Primary request: Create “Sterile Lightbox”, an original French ENT media acquisition and
procedural safety screen. Center a large neutral charcoal viewing surface containing an abstract
synthetic test pattern instead of anatomy. Around it, place an acquisition rail for availability,
anatomical site metadata, right-side laterality, consent, capture time, and provenance. Add a
precise surgical safety checklist and a traceability ledger for scope identifier, reprocessing
cycle, leak test, operator, and release state. Show one acknowledged vigilance notice.
Scene/backdrop: flat full-screen web interface with abstract placeholder media only
Style/medium: polished product UI mockup inspired by radiology lightboxes and sterile instrument
trays, restrained editorial precision
Composition/framing: 16:10 desktop, central viewer dominates, left metadata ruler, right safety
ledger, bottom filmstrip with unavailable slots clearly marked
Color palette: bone white, neutral charcoal, desaturated teal, oxidized copper, restrained amber
Text (verbatim): “Endoscopie ORL”, “Média synthétique”, “Consentement recueilli”,
“Latéralité : droite”, “Traçabilité”, “Vigilance acquittée”
Constraints: UI graphics only, no medical imagery; stable neutral reading environment; provenance
and consent visible; unavailable captures not invented; status uses text, icon and shape
Avoid: humans, bodies, anatomy, gore, medical photos, sci-fi HUD, neon, purple, generic SaaS cards,
logos, watermark
```

Direction retenue : environnement de lecture neutre, métadonnées latérales persistantes et liste de
sécurité structurée comme un registre d'instrumentation.

## 03 — Clinical Atlas

Fichier : `03-clinical-atlas.png`

```text
Use case: ui-mockup
Asset type: high-fidelity desktop web application design prototype, UI only
Primary request: Create “Clinical Atlas”, an original French longitudinal ENT coordination
workspace. A central chronological spine shows synthetic events for lesion discovery, sampling,
coded staging, multidisciplinary review, planned procedure, and signed report. Compact side
modules summarize vestibular testing, voice and swallowing, rhinology, sleep, risks, symptom
duration, laterality, and questionnaires. Clearly distinguish observed, imported, preliminary,
validated, and projected information with words, geometric markers, and line patterns.
Scene/backdrop: flat full-screen web interface with timelines, charts, text, and tables only
Style/medium: polished editorial case-file UI, precise data cartography, quiet and memorable
Composition/framing: 16:10 desktop; narrow vertical section index; sweeping chronology through
the center; staggered evidence cards; compact questionnaire strips
Color palette: parchment white, midnight green, black ink, muted sage, pale blue for imported
data, restrained vermilion for red flags
Text (verbatim): “Parcours ORL longitudinal”, “Données synthétiques”, “Observé”, “Importé”,
“Préliminaire”, “Validé”, “Projeté”, “Aucun diagnostic automatique”
Constraints: interface graphics only; all data synthetic; states legible without color; include
signed and partial states; no automated diagnosis or treatment indication
Avoid: humans, bodies, anatomy, medical photos, generic kanban, rounded pastel tiles, purple
gradients, oversized metrics, logos, watermark
```

Direction retenue : chronologie éditoriale, états de donnée lisibles par motif et vocabulaire, et
modules secondaires organisés comme les onglets d'un dossier clinique.
