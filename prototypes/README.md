# Prototype archive

Each specialty owns `prototypes/<domain>/` containing:

- selected PNG prototypes;
- `prompts.md` with the exact generation prompts;
- `decomposition.md` mapping workbenches to reusable components;
- provenance and licensing notes for any non-generated reference assets.

Synthetic medical imagery must be labeled as synthetic. Real clinical imagery
requires an explicit redistributable license and irreversible de-identification.
